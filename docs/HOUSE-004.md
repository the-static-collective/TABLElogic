## What genuinely ran

The GitHub Actions `house-feast-004.yml` job runs HOUSE-001 through HOUSE-003 using original source-pinned donors and original CANNON cold verification, then checks out original webZ PR #78 at its exact 40-character commit.

The original PR78 `selectSources` and `assemble(question, fetcher, {kind})` functions produce all four artifact kinds **on the same original question**, and the original `verifyReturn` checks each full unsigned receipt. The fetcher **never uses HTTP**: it only reads actual, exact original `README.md` Git objects at PR78's own fixed source commit addresses, using `git cat-file` + `git show`; unavailable Git objects stay UNAVAILABLE. Real original source bytes are measured and hashed by the original webZ code. A source address is not canon.

TABLElogic then checks both interfaces independently, requires literal-question identity with the original native HOUSE-003 record, and writes four distinct `tablelogic.feast-return/v0` files. It also checks forged/tampered public content, altered native questions, and false authority additions fail.

These results are **source-anchored, mechanically reproducible local experiments**—not proof that an unsigned external file was produced by a particular person. SHA-256 protects a local copy against unnoticed changes; it is not a signature. The original CANNON/reLATTE signature check occurred in the preceding original donor stage, **not in this file or a browser**.
